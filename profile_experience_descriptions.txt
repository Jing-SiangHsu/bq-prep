INTRISING NETWORKS

Experience Summary:
Full-stack engineer at Intrising Networks, a Taiwan-based industrial Ethernet switch maker. Most of my work was frontend, across the switch web UI, an internal test platform, and a firmware portal used by partners, plus backend work on authentication, concurrent editing and performance.

Job Description (one item per bullet field):
- Built and maintained features in the switch web UI (AngularJS), including a notifications system with slide-in popups, filters, an unread indicator and light and dark themes, plus new configuration pages for industrial protocols and network features such as Modbus, PROFINET, NAT, tunnels and HSR/PRP.
- Made the switch UI follow user permissions across many pages, and reworked the device panel view so it correctly shows each unit of a stacked switch.
- Led the login and session security work for the switch management interface (web, CLI and Telnet) to meet the IEC 62443 standard: multi-factor login with QR-code setup, concurrent session limits, and the backend login protocol behind it.
- Built much of AutoPVT's frontend in Vue 3: the test menu, the test creation wizard with item selection, the results table and the report, plus the admin pages for users, test sites, test items and live tests.
- Designed how AutoPVT handles many engineers editing the same test at once, including autosave and handling of concurrent edits, so people can work in parallel without overwriting each other.
- Fixed slow pages, including cutting the test catalog load from 3 to 5 seconds to under 500ms, and contributed shared components (markdown editor, status tags, progress bars) to the company's Vue component library.
- Main maintainer of InTriHub, a Vue and Firebase portal for firmware and product information used by partners: built its changelog, download, documentation and FAQ pages, added role-based access, and brought Firebase costs from $300 a month down to the free tier.
